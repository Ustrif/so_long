**SO_LONG**

Hello! This project is a game!
This game only works on Linux.

**How to compile game?**

to compile;

_make_

to run;

_./so_long maps/map1.ber_ // mapx.ber, xE[1..7]

to delete;

_make fclean_

**You can play with your own map.**

You can play with your own map. Just create a .ber file, using __1__ for walls, __0__  for spaces, __C__ for collectible items, __P__  for the starting position, and __E__ for the exit.

to run;

_./so_long map.ber_
